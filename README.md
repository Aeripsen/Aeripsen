# Sepehr Jafari

## Paper

**Unveiling Hierarchical Machine Learning UDP-QUIC Intrusion Detection: Protocol-Aware Flow Analysis and a New Cloud-Generated DDoS Dataset.** First author, with M. Shafi and A. H. Lashkari. SECRYPT 2026, pages 49 to 68. [DOI 10.5220/0015033600004103](https://doi.org/10.5220/0015033600004103).

## Public work

- [agent-gates](https://github.com/Aeripsen/agent-gates): four deterministic checks between a language model and what it is about to say or do (honesty, eligibility, grounding, injection). 152 tests, and the README lists the misses, not only the catches.
- [FlowSentry](https://github.com/Aeripsen/flowsentry): the paper's two-stage UDP/QUIC detector as a service, with a tunable reject knob and a leakage-safe evaluation. It also publishes the benchmark where a simpler baseline beat my architecture.
- [FlowSentry Desk](https://github.com/Aeripsen/flowsentry-desk): an agent that works the queue of flows FlowSentry refuses to call. Six read-only tools, server-checked citations, a close that needs three independent yeses.
- [LedgerSentry](https://github.com/Aeripsen/ledgersentry): the same idea on card fraud, with the review queue priced and the confidence interval printed beside the headline number.
- [boson-bug-reports](https://github.com/Aeripsen/boson-bug-reports): five bugs in a realtime voice API found at a hackathon, each with a reproduction script and raw event logs.
- [quant-facts](https://github.com/Aeripsen/quant-facts): read-only market analysis with an honest backtest harness. Facts and indicators, never advice.
- [youtube-knowledge](https://github.com/Aeripsen/youtube-knowledge): a config-driven pipeline that pulls cited, structured insights out of video transcripts.
- Course study guides for [CSC373](https://github.com/Aeripsen/csc373-study-guide), [CSC343](https://github.com/Aeripsen/csc343-study-guide) and [MAT244](https://github.com/Aeripsen/mat244-study-guide).
